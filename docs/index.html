Aturan inti, aktif di setiap sesi

Saat sesi dimulai, hook SessionStart memanggil wrapper startup yang membacai hooks/core-rules.md dan hooks/startup-extra.md. Ini menaruh konteks default ke sesi: tujuan kerja, batas scope, pola pengambilan keputusan, dan cara kerja ticket.

  • Ubah hanya yang diminta. Tidak ada refactor, rename, atau dependency baru yang tidak diminta.
  • Pikir dulu, lalu pilih cara paling sederhana. Pakai helper yang sudah ada di codebase, meskipun penggantinya cuma satu baris.
  • Logic bisnis punya test positif, negatif, dan batas, dan test dibuktikan gagal dulu sebelum implementasi.
  • Kode efisien: tidak ada query di dalam loop, data diambil seperlunya, dan data besar dipaginasi.
  • Hemat token: cari dulu, baca bagian yang perlu saja, dan batasi output command.
  • "Selesai" hanya diklaim setelah test dijalankan dan hasilnya terlihat.

Selain itu, hook UserPromptSubmit di hooks/hooks.json memindai intent prompt dan menampilkan saran skill paling relevan. Contoh yang sering muncul:

  • fitur baru → /noskill:feature-flow
  • bug/error → /noskill:tiket fix
  • lanjut kerja / resume → /noskill:tiket lanjut
  • tugas umum → /noskill:lazy

Hook hanya menginject startup context dan route intent. Hook tidak otomatis mendaftarkan slash command atau membuat skill /noskill:* muncul di menu. Skill tetap dipanggil secara eksplisit oleh pengguna, kecuali runtime tertentu memang menyediakan dispatch command yang terkontrol.
