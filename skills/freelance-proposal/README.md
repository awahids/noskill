# freelance-proposal

Template dan alur untuk membuat proposal/scoping project freelance web development — struktur fase pengerjaan, format harga dalam Rupiah (IDR), timeline, dan deliverable yang jelas.

## Isinya

- Struktur proposal standar: ringkasan kebutuhan, scope per fase, stack teknologi, timeline, harga (format IDR), syarat & ketentuan
- Panduan estimasi harga (kompleksitas integrasi, tier client, jenis project)
- Panduan nada penulisan (profesional tapi tidak kaku, bahasa Indonesia natural)

## Kapan dipakai

Setiap kali diminta membuat proposal untuk client baru, scoping project freelance, estimasi harga/timeline project, atau kata "proposal", "scoping", "quotation", "penawaran harga" untuk client.
