# user-guide

Menyusun dokumentasi untuk end-user (user guide/manual book) yang mudah dipahami orang non-teknis — bahasa sederhana, panduan step-by-step per fitur, flowchart untuk alur yang punya percabangan, dan slot screenshot aplikasi.

## Isinya

- Perbedaan dengan skill dokumentasi lain (`prd-writer` untuk tim dev, dokumentasi Swagger di `coding-standards` untuk developer konsumen API)
- Alur menyepakati outline dulu untuk dokumen besar (>5 section)
- Struktur dokumen: judul & pembuka, daftar isi, getting started, panduan per fitur, flowchart Mermaid, screenshot, FAQ, kontak bantuan
- Aturan bahasa (kata kerja aktif, hindari istilah teknis, nama tombol persis seperti di aplikasi)

## Kapan dipakai

Setiap kali diminta "buatkan user guide", "panduan pengguna", "manual book", "dokumentasi untuk user/karyawan/admin", atau "cara pakai aplikasi ini untuk end-user".

## Terkait

- `prd-writer` — sumber requirement/fitur untuk dijadikan acuan konten
- `mockup-prototype` — sumber visual/screenshot pengganti kalau screenshot asli belum ada
- `docx` (built-in) — kalau dibutuhkan versi Word untuk distribusi formal
