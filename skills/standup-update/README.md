# standup-update

Merangkum aktivitas kerja (commit, task, progress) menjadi update standup harian atau status report mingguan dengan format Yesterday/Today/Blockers atau format Notion-friendly.

## Isinya

- Format standard Daily Standup (Yesterday / Today / Blockers)
- Format alternatif Weekly/Project Status (Notion-friendly)
- Cara mengubah bahasa proses (commit message teknis) jadi bahasa hasil
- Pengelompokan per project/area kalau kerja di beberapa hal sekaligus

## Kapan dipakai

Setiap kali diminta bikin "standup", "update harian", "status report", "progress report", atau merangkum daftar commit/task/aktivitas jadi laporan rapi.
